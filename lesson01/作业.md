## 附加题（选做，锻炼 10 分钟）

**目标**：把课程文件夹变成 GitHub 上的仓库。完整链路 6 步，缺一步都会卡：

```bash
# 第 0 步（网页操作）：GitHub 上新建空仓库 testdev-course，不要勾 README
cd C:\Users\12607\Desktop\测试开发学习
git init                                      # 1. 建本地仓库
git add .                                     # 2. 文件进暂存区（先确认 .gitignore 已存在！）
git commit -m "lesson01: first pytest test"   # 3. 生成第一个提交
git remote add origin https://github.com/你的用户名/testdev-course.git   # 4. 登记远端地址
git branch -M main                            # 5. 分支改名 main（对齐 GitHub 默认）
git push -u origin main                       # 6. 首次推送并建立追踪
```

**之后日常只需要 3 条**：`git add .` → `git commit -m "说明"` → `git push`（第 6 步的 `-u` 已经把 main 和 origin/main 绑定了，不用再写全）。

> 只写 `git push` 会报错，是因为它在等"当前分支跟着谁"这条追踪关系——这正是第 6 步 `-u` 建立的东西。
