# 第 1 课作业（下次上课前完成）

## 作业 1：用例设计（重点！面试第一考点）

目标功能：一个网站的「用户登录」框（账号 + 密码 + 登录按钮）

要求：
1. 先划分**等价类**（有效 / 无效），写出你的划分依据
2. 用**边界值分析**补充：假设密码长度限制 6-20 位，账号是 11 位手机号
3. 写出至少 **15 条**测试用例，每条包含 5 要素：
   用例编号 / 前置条件 / 操作步骤 / 测试数据 / 预期结果
   （建议存成 `lesson01/登录框测试用例.md`，以后面试前直接翻）
4. 至少包含 3 条「非常规但真实」的用例
   （提示：超长字符串、全角数字、`' or 1=1 --`——这是你安全背景的加分项）
