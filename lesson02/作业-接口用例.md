# 第 2 课作业 · 接口用例（xuanwu 玄武商城）v2

> 对象：xuanwu 后端（服务已在 `127.0.0.1:8000` 运行，`/docs` 可看全量接口）。
> 本版 16 条由老师代写（标准答案），**你必须能讲出每条的"为什么"**；另留 5 条新题自己写（第 5 节）。

## 0. 被测接口登记（源码实证）

| 代号 | 方法 + 路径 | 用途 | 鉴权 | 关键字段与约束 |
|---|---|---|---|---|
| A | `POST /api/v1/auth/register` | 注册（成功 **201**） | 否 | `email` ≤120 合法邮箱（自动转小写）；`phone` 选填 `1[3-9]\d{9}`；`password` **8-64 位且须含字母+数字**；`nickname` 选填 ≤20 |
| B | `POST /api/v1/orders` | 提交订单 | 是 `Bearer <JWT>` | `address_id` int；`cart_item_ids` int 列表 **≥1**；`remark` ≤200；Header `Idempotency-Key` |

## 1. 契约速查（写"预期"的唯一依据）

| 场景 | HTTP | code | 备注 |
|---|---|---|---|
| 成功 | 200（注册 201） | 0 | `{"code":0,"message":"ok","data":…}` |
| 参数校验失败 | **400**（不是 422） | 40001 | `data.errors=[{field, reason}]` |
| 未带 token | 401 | 40100 | |
| token 无效/过期 | 401 | 40101 | |
| 权限不足 | 403 | 40300 | 普通用户调 admin |
| 资源不存在/非本人资源 | 404 | 40400 | 归属校验失败也用它，不泄漏存在性 |
| 邮箱/手机号已注册 | 409 | 40900 | |
| 库存不足 | 409 | 40901 | 事务回滚 |
| 状态不支持 | 409 | 40902 | 如商品已下架 |
| 幂等冲突 | 409 | 40903 | 同 key 不同请求体 |
| 服务器异常 | 500 | 50000 | 不返回堆栈 |

分页：`page≥1`、`size` 1-100、`total=0 → pages=0`。任何响应不出现 `hashed_password`。

## 2. 前置数据链（下单测试怎么造数据）

```
① 注册  POST /api/v1/auth/register
② 登录  POST /api/v1/auth/login  → data.token
③ 地址  POST /api/v1/addresses   {receiver, phone, province, city, district, detail(5-200), is_default}
④ 加购  POST /api/v1/cart        {sku_id, quantity(1-999)}  → 返回 cart_item.id
⑤ 下单  POST /api/v1/orders      {address_id, cart_item_ids:[cart_item.id]}
```

商品/SKU 数据来自 `backend/scripts/seed_demo.py`（已灌 33 个商品）；管理员账号用 `create_admin.py` 创建。

## 3. 用例表（16 条）

### A 组：注册（7 条）

| 编号 | 目的 | 请求（方法+路径+头+体） | 前置 | 预期（状态码+body+DB） | 依据 |
|---|---|---|---|---|---|
| API01 | 注册成功（基线） | `POST /api/v1/auth/register` `{"email":"Test01@Xuanwu.dev","phone":"13800138000","password":"Abc12345","nickname":"测试号"}` | 邮箱/手机号未注册 | 201；code=0；data.email 已转小写 `test01@xuanwu.dev`；data 无 hashed_password；users +1 且密码为哈希 | 基线 / ③ |
| API02 | 密码 7 位（下边界外） | 同上 `{"email":"test02@xuanwu.dev","password":"Abc1234"}` | 无 | 400；code=40001；errors[0].field=password；未入库 | 边界（8-64） |
| API03 | 密码 65 位（上边界外） | `{"email":"test03@xuanwu.dev","password":"Aa1"+62 个 a}` | 无 | 400；code=40001；field=password | 边界 |
| API04 | 手机号格式非法 | `{"email":"test04@xuanwu.dev","password":"Abc12345","phone":"1280013800"}` | 无 | 400；code=40001；field=phone（regex `1[3-9]\d{9}`） | 输入域规则 |
| API05 | 类型混淆：password 传数字 | `{"email":"test05@xuanwu.dev","password":12345678}` | 无 | 400；code=40001；field=password（应为字符串） | 类型 |
| API06 | 重复注册（同邮箱） | 重复提交 API01 的邮箱 | 该邮箱已注册 | 409；code=40900；message「该邮箱已注册」；users 不增加 | 业务规则 |
| API07 | 安全：nickname 存 XSS payload | `{"email":"test07@xuanwu.dev","password":"Abc12345","nickname":"<img src=x>"}` | 无 | 201；原样存储为字面量（不执行）；响应 JSON 中为字符串；DB 字段完整未截断 | 安全 ⑥ |

### B 组：提交订单（9 条）

| 编号 | 目的 | 请求（方法+路径+头+体） | 前置 | 预期（状态码+body+DB） | 依据 |
|---|---|---|---|---|---|
| API08 | 正常下单（基线） | `POST /api/v1/orders`，Header `Authorization: Bearer <token>`，body `{"address_id":1,"cart_item_ids":[1]}` | 已登录；地址存在；购物车有项；库存足 | 200；code=0；data.order_no 非空、status=pending；total_amount 与结算页一致；DB：orders +1、order_items 快照正确、sku.stock 扣减、对应 cart_items 被删除 | 基线 / ⑤ |
| API09 | 空购物车项（边界） | `{"address_id":1,"cart_item_ids":[]}` | 已登录 | 400；code=40001；field=cart_item_ids（min_length=1） | 边界 |
| API10 | 类型混淆：cart_item_ids 传字符串 | `{"address_id":1,"cart_item_ids":"1,2"}` | 已登录 | 400；code=40001；field=cart_item_ids | 类型 |
| API11 | 未带 token | 不传 Authorization 头 | — | 401；code=40100；message「请先登录」 | 鉴权 L1 |
| API12 | 伪造 token（改 1 个字符） | `Authorization: Bearer eyJhbGciOiJIUzI1NiJ9.xxx`（篡改签名） | — | 401；code=40101；message「登录凭证无效」 | 鉴权 |
| API13 | 水平越权：A 的 token 提交 B 的购物车项 | 带用户 A 的 token，body 里放用户 B 的 `cart_item_ids` | A、B 各有购物车项 | 404；code=40400；message「部分购物车项不存在」；DB 无新订单、库存不变 | 鉴权 / ④ |
| API14 | 垂直越权：普通用户调管理端 | `GET /api/v1/admin/orders`，带普通用户 token | 普通用户已登录 | 403；code=40300；message「权限不足」；不返回任何订单数据 | 鉴权 L2 |
| API15 | 库存不足（业务规则） | 提交订单，购物车数量 **2**，SKU 库存 **1** | admin 先把目标 SKU 库存改为 1；购物车该 SKU 数量 2 | 409；code=40901；message「库存不足：<sku_code>」；**事务回滚**：库存仍为 1、无订单产生、购物车项仍在 | 业务规则 ④⑤ |
| API16 | 幂等重放（业务规则） | Header `Idempotency-Key: demo-001`，同 body 连发两次 | 已登录；库存足 | 第 1 次 200 生成 order_no；第 2 次 200 返回**同一 order_no**；orders 仍 1 条；库存只扣 1 次 | ⑤ 幂等 |
